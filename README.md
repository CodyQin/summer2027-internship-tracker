# Summer 2027 Internship Tracker · 2027 暑期美国实习追踪

**109 家美国科技公司 · Summer 2027 SWE/ML/AI 实习 · 逐公司一手核实 · 可直接点击申请**

A verified, one-click-applicable tracker of **Summer 2027 tech internships at 109 US companies** — every row checked against the company's own ATS job board (not crowdsourced copy-paste), with status, direction tags, timelines, deadlines, and F-1/visa notes.

## 使用 · How to use

1. 下载 `tracker.html`,双击用浏览器打开(纯静态、无依赖、不联网)
2. 筛选:🟢 立即投 / 🤖 AI 强匹配 / ⚙️ 通用 SWE / 🎮 游戏娱乐 / 搜索框
3. 「申请 →」直达岗位页;深链失效时用「官网 ↗」进官方看板重搜
4. 「我的进度」下拉(已投/OA/约面/Offer/拒)保存在你浏览器本地;📤 可导出 JSON 备份/迁移
5. 量化板块(12 家)默认隐藏——工具栏「📈 量化系统」或「🙈」开关可见

Open `tracker.html` in any browser. Everything runs locally: filters, search, and a personal progress column persisted in localStorage (export/import included).

## 方法论 · Methodology

- 数据核至于 **2026-09-04**,由**七轮共 31 路并行 AI 调研**(Claude Code 多 agent 编排)逐公司核实
- 每家公司直接查询其 ATS 看板 API(Greenhouse `boards-api` / Ashby `posting-api` / Lever / Workday CXS)或官方 careers 页面;JS 重的门户用多源搜索快照佐证并注明
- **日期纪律**:上一周期(Summer 2026)的过期岗位一律不计为在招;只有 2027 年份标注或常设滚动岗计为开放
- 每条状态结论附证据 URL;薪酬来自岗位页或聚合站(levels.fyi 等,已标注二手)
- 发现过众包表的错链/错标(如把字节岗位标成 Cisco),故坚持一手核实

## 维护 · Maintenance

快照制:本仓库按周期更新(9–10 月高峰每周,之后递减)。链接会失效,投递前以官方页面为准。欢迎开 Issue 报错链/新岗。

This is a periodic snapshot (weekly during the Aug–Oct peak). Open an Issue to report dead links or new openings.
